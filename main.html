TrenchBot commands

Use these in Telegram with the bot.

  • /start — Welcome and command list
  • /help — Full command reference
  • /price [pair] — Get price (default TRCH/ETH)
  • /order buy|sell <amount> [pair] — Place market order
  • /balance — Simulated balance
  • /positions — Open positions
  • /cancel <order_id> — Cancel order
  • /history [filled|pending] — Recent orders
  • /trenchers — Trenchers NFT contract info
  • /signals — Signal channel
  • /stats — Engine stats
  • /pairs — Supported pairs
  • /about — Bot version and addresses

How to mint

  1. Connect your wallet above.
  2. Paste the deployed Trenchers contract address and click Set contract.
  3. Check mint price (shown in stats). Send at least that much ETH when minting.
  4. Mint one: enter ETH amount ≥ mint price and click Mint 1 Trencher.
  5. Mint batch: enter count (1–32) and send (mint price × count) ETH, then click Mint batch.
  6. Load my NFTs to see your balance.

FAQ

What is TimeToTrade? Web UI for TrenchBot and Trenchers NFT. Connect wallet, set contract, mint.

What is TrenchBot? Telegram bot for trading (simulated orders, price, balance, positions).

What are Trenchers? NFT collection, 10,000 supply, symbol TRCH. Mint with ETH at mint price.

Which network? Use the same network as the deployed Trenchers contract (see Chain ID above).

Quick tips

  • Deploy Trenchers.sol (Solidity) first; copy the contract address into the field above.
  • Mint price is set by the contract owner; check the Mint price stat before minting.
  • Batch mint saves gas when minting multiple Trenchers in one tx (max 32 per batch).
  • TrenchBot is a separate Python engine; run it with your Telegram bot token to enable /price, /order, etc.
  • Trenchers treasury and minter addresses are set in the contract constructor at deploy.

Contract info

Trenchers: ERC721, name "Trenchers", symbol "TRCH", max supply 10,000. Owner can set base URI and mint price; minter or owner can mint (with payment to treasury). Pause supported. No upgrade; immutable treasury.

About

TimeToTrade is the web interface for the TrenchBot ecosystem. Connect your wallet to view and mint Trenchers NFTs (10,000 supply). TrenchBot runs on Telegram for trading commands. Set the Trenchers contract address after deployment.

Reference

TimeToTrade — single-page web UI. TrenchBot — Python Telegram bot (TrenchBot.py). Trenchers — Solidity NFT (Trenchers.sol). All config and addresses are pre-populated or set at deploy; replace constructor addresses for mainnet. Unique naming: TRCH_ errors, TrencherMinted events, trenchTreasury immutable. Safe for EVM mainnets: ReentrancyGuard, Ownable, supply cap 10000, batch mint cap 32. Mint flow: user sends ETH to mint() or mintBatch(); treasury receives payment. Owner can setBaseURI, setMintPriceWei, setMinter, setPaused. TrenchBot commands: start help price order balance positions cancel history trenchers signals stats pairs about. Default pairs: TRCH/ETH, TRCH/USDT, ETH/USDT. Rate limit and max orders per user configurable in bot env. Web: connect wallet (ethers v6), set Trenchers contract, view total minted and mint price, load owned balance, mint one or batch. Chain ID displayed for network check.
